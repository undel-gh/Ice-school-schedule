# Эксплуатационная документация

Этот раздел предназначен для эксплуатации системы расписания, посещаемости и абонементов школы фигурного катания.

Документация разделена по ролям:

1. [Руководство системного администратора](01_Руководство_системного_администратора.md) — развертывание, конфигурация, резервное копирование, мониторинг, обслуживание, обновление и аварийное восстановление.
2. [Руководство менеджера](02_Руководство_менеджера.md) — настройка школы, расписания и абонементов, ежедневные операции и обработка исключительных ситуаций.
3. [Руководство тренера](03_Руководство_тренера.md) — работа с расписанием, составом занятия и посещаемостью.
4. [Руководство пользователя](04_Руководство_пользователя.md) — вход учеников и родителей, расписание, ответы «Буду/Не буду», абонемент, права и история посещений.

## Статус и область действия

Документация описывает текущую пилотную односерверную конфигурацию приложения на Django/PostgreSQL с Docker Compose, Gunicorn и Caddy. Поведение бизнес-процессов должно соответствовать реализованным application services и web-интерфейсу. При расхождении документации и кода приоритет имеет код текущей версии; расхождение должно быть исправлено в документации или реализации отдельным изменением.

Система ведет расписание, RSVP, посещаемость, абонементы и права на посещения/отработки. Она **не является бухгалтерской или платежной системой**: суммы, скидки, задолженности, возвраты и фактические платежи учитываются вне приложения. В интерфейсе могут фиксироваться отдельные бизнес-факты вроде подтверждения оплаты предусмотренной правилами услуги, но приложение не рассчитывает денежные суммы.

## Связанная техническая документация

В каталоге `docs/` также находятся спецификация системы, модель предметной области, state machines/domain events и подробная спецификация моделей и application services. Эти документы предназначены прежде всего для разработки и архитектурного сопровождения; эксплуатационные руководства выше являются основными документами для повседневной работы.
